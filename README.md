# To-Do List App

## Project Description

The To-Do List App is a simple web application that helps users manage their daily tasks.

Users can add new tasks, mark tasks as completed, undo completed tasks, and delete tasks.

The application also uses browser Local Storage to save tasks so that they remain available after refreshing the page.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Save tasks using Local Storage
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
